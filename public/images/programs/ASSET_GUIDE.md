# Program card imagery

These five course-card images are locally hosted, generated with the built-in ImageGen tool on 2026-10-13, and exported as WebP at 1280 × 800 (16:10). The source is ImageGen; the assets are illustrative program imagery, not documentary evidence, endorsements, or photographs of named students or staff. No external image host or logo is embedded. They do not establish that a pictured learner, teacher, workplace, or location is affiliated with Topica; obtain media-owner review before making any such claim.

`data/programs.ts` is the source of truth that maps each program to its image. The card uses an explicit Vietnamese alt prefix (“Ảnh minh họa cho ngành…”) so assistive technology does not present generated scenes as real student portraits. Keep the 16:10 crop, local hosting, distinct subject per major, and illustrative status when changing these assets. Avoid generic device/book imagery, readable AI-generated text, logos, or implying a real testimonial. Review each image at card size on both mobile and desktop after replacement.

The images were generated using five separate ImageGen prompts, one per major. Each requested premium, human-centered editorial photography with a restrained navy/gold color grade, authentic Vietnamese young-adult context, horizontal 16:10 composition, and no readable text/logo/watermark; the subject line in the table differentiates each prompt.
